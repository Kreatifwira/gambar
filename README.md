# AI Music Studio

Aplikasi web untuk membuat lirik lagu, prompt visual per baris lirik, dan galeri gambar secara berurutan.

## Stack
- React + Vite
- Supabase Auth, Postgres, Storage, Edge Functions
- OpenAI, DeepSeek, dan Gemini API melalui backend aman

## Status
Fondasi database Supabase sudah disiapkan. Frontend dan Edge Functions menyusul setelah konfigurasi deployment dan API provider tersedia.
